PROJECT IMAGES

One folder per project. The folder name must match the project's "id"
in assets/sections/development.js or assets/sections/design.js.

  assets/img/projects/careerlens/cover.png        <- card thumbnail ("cover")
  assets/img/projects/careerlens/moodboard.png    <- listed under "images"

Tips
- PNG, JPG or WebP all work. Keep each file under about 500 KB so the page stays fast.
- Card thumbnails look best at a 16:9 shape, for example 1600 x 900.
- Gallery images can be any shape. They show at full width in the pop-up.
- Use lowercase file names without spaces, e.g. app-structure.png.
